# self_report

Self-report / check-in bounded context — the patient's on-device symptom,
pain, mood, and vitals journal. PHI, on-device only (no server endpoint).

A journal, NOT a symptom checker: the symptom/body-region catalogs are closed
reference data and carry no clinical interpretation or advice.
